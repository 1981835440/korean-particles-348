━━ 专题一 · 이/가 与 은/는（主格 · 主题） ━━
   要领：本专题只在 이 · 가 · 은 · 는 中选填。① 名词有收音（末音是辅音）→ 이／은；无收音（末音是元音）→ 가／는。② 说“谁／什么”（新信息、存在句、疑问词主语、客观现象、强调主语）用 이／가；把已知事物摆上话题位来谈（介绍、对比、评价）用 은／는。

【答案与解析 第 1–40 题】
1. 는 — 介绍身份，主语是已知话题 → 는；저 无收音。 ▸ 我是学生。
2. 은 — 话题 + 이름 有收音ㅁ → 은。 ▸ 我叫金民秀。
3. 는（可接受：가） — 家人是已知话题 → 는（어머니 无收音）；答 가 也可，但话题句更自然。 ▸ 我妈妈做饭真拿手。
4. 은 — 评价手头话题 → 은；제품 有收音ㅂ。 ▸ 这个产品最近人气很旺。
5. 은／이 — 大主语（场所话题）用은（방 有收音ㅁ）；小主语창문 有收音ㅁ，新信息用이。 ▸ 我们房间有两扇窗户。
6. 은／이 — 场所话题用은（교실 有收音ㄹ）；存在的主体用이（책상 有收音ㅈ）。 ▸ 教室里有二十套课桌。
7. 가 — 感叹眼前的新情况，客观描述用가（날씨 无收音）。 ▸ 今天天气真好啊。
8. 가 — 自然现象初次陈述用가（비 无收音）。 ▸ 外面正下着雨。
9. 가 — 存在句中新出现的事物用가；量词한 마리前面不加格助词。 ▸ 房间里有一只猫。
10. 가 — 疑问代词作未知主语只能用가，绝不能写누구는。 ▸ 谁把这个包裹拿走了？
11. 가 — 回答“谁”、强调主语本身 → 가。 ▸ ——谁开的窗？——是我开的。
12. 이／이 — 条件从句主语用主格；물 有收音ㄹ→이，사람 有收音ㅁ→이。 ▸ 没有水人就活不了。
13. 은／이 — 话题用은（문장 有收音ㅇ）；新信息“뜻”有收音ㅅ → 이。 ▸ 这个句子的意思我不明白。
14. 는／는 — 前后对照表“这个…那个…”的对比，都用는（两词皆无收音）。 ▸ 他喜欢咖啡，但不喜欢茶。
15. 은／은 — 分别陈述两人：형 有收音ㅁ → 은，동생 有收音ㅇ → 은。 ▸ 哥哥个儿高，弟弟性格好。
16. 은／가 — 话题한국 有收音ㄱ → 은；新信息인구 无收音 → 가。 ▸ 韩国人口在不断减少。
17. 은 — 从句主语用가（제가），主句把“말”放话题位 → 은（말 有收音ㄹ）。 ▸ 我说的话不是事实。
18. 는（可接受：가） — 陈述已知人物的情况 → 는（친구 无收音）。 ▸ 我朋友出生在加拿大。
19. 은 — 大主语话题用은（휴대폰 有收音ㄴ），小主语카메라用가。 ▸ 新买的手机摄像头特别好。
20. 는／은 — 话题우리나라 无收音 → 는；季节对比여름은…겨울은…（겨울 有收音ㄹ）。 ▸ 我们国家夏天热、冬天冷。
21. 이 — 感叹时间流逝，新信息用主格；시간 有收音ㄴ → 이。 ▸ 时间过得真快啊。
22. 는 — 对已知对象作评价 → 는（문제 无收音）。 ▸ 那道题不像想象的那么容易。
23. 은／가 — 话题고향 有收音ㅇ → 은；并列小主语공기 无收音 → 가。 ▸ 我故乡山多、空气也好。
24. 가 — “…에는 …이/가 있다”结构中存在的主体用가（영화 无收音）。 ▸ 其中有三部我喜欢的电影。
25. 은 — 转述已知人物的情况 → 은（그분 有收音ㄴ）。 ▸ 听说他昨天没能来。
26. 은／이 — 泛指话题“人”有收音ㅁ→은；其下新信息생각 有收音ㄱ→이。 ▸ 每个人想法都不一样。
27. 가 — 무섭다 的主体用이/가；벌레 无收音→가。 ▸ 我怕虫子。
28. 가 — 나＋가 缩合成 내가，空格只补가。 ▸ 那个我来做。
29. 이 — 感叹眼前新看到的东西，主体用이（옷 有收音ㅂ）。 ▸ 哇，这件衣服真好看！
30. 을 — 저녁 有收音ㄱ → 을。 ▸ 我今天晚饭还没吃。
31. 를 — 저 固定接 를（저를），不写 저을。 ▸ 请一定帮帮我。
32. 을 — 물 有收音ㄹ，仍接을（물을）；ㄹ 脱落只发生在(으)로（물로）。 ▸ 我每天喝八杯水。
33. 을／를 — 빵 有收音ㅂ → 을；우유 无收音 → 를。 ▸ 吃了面包，喝了牛奶。
34. 을 — 과일 有收音ㄹ→을（과일을）。 ▸ 昨天在市场买了几样水果。
35. 을 — 계획 有收音ㄹ→을（계획을 세우다 是固定搭配）。 ▸ 重新制定计划。
36. 을 — 손 有收音ㄴ → 을。 ▸ 一到家就先洗手。
37. 을 — 사실 有收音ㄹ→을（사실을）。 ▸ 那件事我也已经知道了。
38. 을 — 의견 有收音ㄴ → 을。 ▸ 下面我谈谈我的意见。
39. 을 — 책 有收音ㄱ → 을。 ▸ 你在读什么书？
40. 를 — 저 → 를（习惯用法）。 ▸ 你为什么老是看我？

【答案与解析 第 41–80 题】
41. 을 — 시간 有收音ㄴ → 을。 ▸ 珍惜时间也是一种节约。
42. 를 — 한국어 无收音 → 를。 ▸ 我会说一点韩语。
43. 를 — 서류 无收音 → 를。 ▸ 请把这份文件在明天之前整理好。
44. 을／를 — 약속 有收音ㅅ → 을；신뢰 无收音 → 를。 ▸ 守约的人能赢得信任。
45. 를 — 자료 无收音 → 를。 ▸ 准备好了会议资料。
46. 을 — 물 以ㄹ收音结尾，仍加을（물을）。 ▸ 喝一杯水。
47. 를 — 否定句的宾语仍用을/를；커피 无收音→를。 ▸ 我不喝咖啡。
48. 을 — 시키다 的宾语；음식 有收音ㄱ→을。 ▸ 点了外卖。
49. 의（可接受：제） — 领属“我的朋友”→ 저의，习惯缩写成 제。 ▸ 我朋友昨天结婚了。
50. 의 — “歌的歌词”→ 의。 ▸ 这首歌的歌词真美。
51. 의／를 — “公司的地址”→ 의；“告诉（地址）”的宾语用를（주소 无收音）。 ▸ 我把我们公司的地址告诉您。
52. 의 — 同位/领属“那起事件的负责记者”→ 의。 ▸ 我是那起事件的负责记者。
53. 의 — 疑问 + 领属“谁的伞”→ 의。 ▸ 这是谁的伞？
54. 의 — “国家的首都”→ 의；注意“首尔”无收音，接는。 ▸ 我们国家的首都是首尔。
55. 의 — “单词的意思”→ 의。（선생님은呼格，不是의） ▸ 老师，请告诉我这个单词的意思。
56. 의 — “作家的新作小说”→ 의。 ▸ 那位作家的新小说成了畅销书。
57. 의 — “团队的一员”（同位领属）→ 의。 ▸ 我认为自己是这个团队的一员。
58. 의 — “会议的议题”→ 의。 ▸ 今天会议的议题有三项。
59. 의 — “学习的乐趣”→ 의。 ▸ 他说他感受到了学习的乐趣。
60. 의 — “首尔的北边”→ 의（에서 表出生的动作场所）。 ▸ 我出生在首尔北边。
61. 의 — “旅行的回忆”→ 의。 ▸ 这张照片是2015年夏天旅行的回忆。
62. 의 — 亲属领属，口语可省，但填空按书面写 의。 ▸ 我妈妈做的饭菜最好吃。
63. 의 — 所属关系用의：누구의 가방。 ▸ 这是谁的包？
64. 의 — 의 表“内容·范围”，不只是所属。 ▸ 韩语的发音很难。
65. 의 — “今天的天气”，时间＋의＋名词。 ▸ 今天天气怎么样？
66. 에 — 动作的归着点（去哪）→ 에。 ▸ 我去学校。
67. 에 — 具体时点 → 에。 ▸ 三点见吧。
68. 에 — 时间名词后接 에（에 无变体）。 ▸ 周末回故乡。
69. 에 — 静态存在场所（…에 있다）→ 에。 ▸ 桌子上有笔记本。
