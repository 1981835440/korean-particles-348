# 韩语助词 348 题 · 专项练习

一套可点选的韩语助词（조사）专项题库：**348 道裸填空题**，16 个专题，每题带中文词义、解析、译文，新增题另附 **特殊情况** 与 **日常常用** 两行说明。

- 在线练习（GitHub Pages）：<https://1981835440.github.io/korean-particles-348/>
- Word 版（含答案解析）：[`assets/korean-particles-348.docx`](assets/korean-particles-348.docx)

## 这版加了什么

在原有 300 题基础上，**不新增专题**，而是往 16 个专题里各插入 3 题（共 48 题），专门覆盖两类最容易错、也最常用的东西：

1. **特殊情况**：基本规则之外会写错的点。例如
   - 缩合主格：나＋가→내가、저＋가→제가、너＋가→네가（读［니가］）、누구＋가→누가
   - ㄹ 收音：물을·과일을·계획을 照常加을，ㄹ 脱落只发生在 (으)로（물로·서울로）
   - 아니다／되다 前用이/가；있다/없다 的主体也用이/가；心理形容词（무섭다·싫다）主体用이/가
   - 밖에 必须配否定；조차／마저 的否定呼应；은커녕／는커녕“别说…连…”
   - 口语助词 보고·더러·에다가；呼格 야／아；助词叠加 에는·에서는·한테는
   - 에 只表“存在/到达”，动作场所必须에서；에게 只接人，公司机关用에
2. **日常常用**：点单、打车、通勤、看病买药、银行、外卖、职场联络、约见面等场景里的真实说法。

判分后会显示三块内容：**解析 → 特殊情况 → 日常常用 → 译文**。

## 网页版功能

- 手机优先：点下面助词卡片拼答案，两个空按顺序点两次
- 即时判分：正确变绿、错误标红并给出正确答案
- 判分后显示「解析 / 特殊情况 / 日常常用 / 译文」
- 进度与错题默认存在浏览器本地（localStorage），可“只重做错题”
- 可选云端同步：登录后每题自动上传，换设备可恢复错题本（见下文配置）
- 「导出我的答案」一键复制全部作答，方便发给老师或 AI 批改
- 目录面板可跳专题、看每个专题的正确数

## 云端同步（可选，Supabase）

不配置时一切仍是纯本地，不影响使用。配置后：登录 → 每题作答自动入库 → 换设备登录即可恢复错题本。

1. 注册 <https://supabase.com>，新建 Project（区域选 Singapore / Tokyo 延迟更低），记下数据库密码。
2. 打开 **SQL Editor**，把 [`supabase/schema.sql`](supabase/schema.sql) 全文粘进去执行。它会建 `attempts` 表、开启 RLS（每人只能读写自己的行）、并建 `wrong_book` 错题视图。
3. **Project Settings → API** 复制两个值：
   - `Project URL`（`https://xxxx.supabase.co`）
   - `anon` / `publishable` key
4. 填进 [`config.js`](config.js)：

```js
window.CLOUD_CONFIG = {
  provider: 'supabase',
  url: 'https://xxxx.supabase.co',
  anonKey: 'eyJhbGciOi...',
  table: 'attempts'
};
```

5. 建议关掉邮箱确认（省一步）：**Authentication → Sign In / Providers → Email → Confirm email** 关掉。开着也能用，注册后去邮箱点确认链接再登录。
6. 打开网页 → 右上角「目录·统计」→ 底部「云端同步」→ 注册 / 登录。

`anonKey` 是公开信息，可以放在仓库里；权限由第 2 步的 RLS 策略兜底，别人拿到 key 也读不到你的记录。

### 绑定自己的域名

1. 域名商处加一条 CNAME：`kr` → `1981835440.github.io`（换成你的仓库地址）。
2. GitHub 仓库 **Settings → Pages → Custom domain** 填入 `kr.你的域名`，勾选 Enforce HTTPS。
3. 等证书签发（几分钟到半小时）。Supabase 侧不用改配置——邮箱密码登录不校验来源域名；只有以后加微信/Google 登录时才需要在 **Authentication → URL Configuration** 里补 Redirect URL。

## 本地使用 / 重新生成

直接双击 `index.html` 即可练习，无需服务器。

```bash

npm init -y
npm i docx
node check.js        # 348 题，校验通过
node build_html.js   # 生成网页版 + 纯文本版
node build.js        # 生成 Word 版
```

## 答案核对

`check.js` 除了检查“空格数＝答案数、括注配对、题号连续”之外，还会按收音规则校验每一道单助词题：

- 有收音 → 이·은·을·과·이랑·이나；无收音 → 가·는·를·와·랑·나
- (으)로：有收音 → 으로；无收音或以 ㄹ 收音 → 로

当前 **348 题全部通过**。本次同时修正了原稿 10 处收音不符的答案（如 물＋를 → 물＋을、창문＋가 → 창문＋이、동생＋는 → 동생＋은）。

题目用于自学与教学，解析里的语法判断按标准韩国语（표준어）。若你觉得某题“另一个答案也说得通”，多半是语用差异，欢迎开 Issue 讨论。
